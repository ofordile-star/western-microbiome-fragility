This repository contains analysis code, processed data summaries, figures, and supporting materials for the articles:

**Ofordile ON.**

**Does gut microbial richness lost with industrialisation matter for infection? A two-direction test in Gambian toddlers (scripts 00–09).**

The project tests whether lower gut microbial richness is associated with greater infection susceptibility, using longitudinal data from Gambian toddlers and a two-direction analysis of illness and subsequent infection.

The repository integrates:

* the **IHAT-GUT longitudinal cohort** of 452 Gambian toddlers
* **microbial richness, diversity and functional redundancy** analyses
* **PICRUSt2 gene-content profiles** and longitudinal infection outcomes

**Symbiotic intelligence in the gut: testing network-based resilience in Gambian toddlers (scripts 10–17).**

The project tests whether gut microbiome resilience is better explained by network topology and adaptive community behaviour than by richness alone, using longitudinal data from the IHAT-GUT cohort.

The repository integrates:

* the **IHAT-GUT longitudinal cohort** of 452 Gambian toddlers
* **microbial network topology** and ecological state analyses
* tests of **prediction, hysteresis, keystone taxa and self-repair**

**Tipping points in gut ecology: a hidden resilience deficit in industrialised microbiomes (scripts 18–22).**

The project develops an ecological resilience framework for understanding industrialised gut microbiomes, arguing that reduced genus-level richness and functional redundancy place these systems closer to critical ecological tipping points.

The repository integrates evidence from:

* the **IHAT-GUT longitudinal cohort** in Gambian children
* **astronaut microbiome dynamics** during long-duration spaceflight
* **ecological resilience and redundancy theory**
